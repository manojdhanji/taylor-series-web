About This App

Taylor Series Visualizer

This tool plots a function f(x) and its Taylor polynomial Tₙ(x) to show how the approximation improves as the order increases.

Features

  • Preset functions
  • Adjustable Taylor order
  • Real-time plotting
  • Canvas-based grid and axes
